# Solana wallet integration

Generated by `web3 add solana-wallet`.

## Files

| Path | Purpose |
|------|---------|
| `lib/solana/cluster.ts` | Cluster + RPC configuration |
| `components/solana/providers.tsx` | Wallet adapter provider |
| `components/solana/connect-button.tsx` | Wallet multi-button UI |
| `lib/solana/transaction.ts` | Send / confirm transactions |
| `hooks/use-program-account.ts` | Read on-chain account data |
| `hooks/use-program-write.ts` | Build and send program transactions |

## Setup

1. Install wallet adapter packages (CLI merges when possible).

2. Add to `.env.local`:

   ```env
   NEXT_PUBLIC_SOLANA_RPC=https://api.devnet.solana.com
   ```

3. Wrap your layout with `SolanaProviders` and use `ConnectButton` from `@/components/solana/connect-button`.
