# wagmi integration

Generated by web3-devkit.

## Setup

1. Wrap your app in `Web3Providers` (see `components/web3/providers.tsx`).
2. Add `ConnectButton` where needed.
3. Use `useContractRead` / `useContractWrite` with your ABI.

## Env

```env
NEXT_PUBLIC_WALLET_CONNECT_PROJECT_ID=your_project_id
NEXT_PUBLIC_RPC_URL=https://mainnet.base.org
NEXT_PUBLIC_CHAIN_ID=8453
```

## Install

```bash
npm install wagmi viem @tanstack/react-query
```

## tsconfig paths

Ensure `@/*` maps to your app root (default in Next.js).
