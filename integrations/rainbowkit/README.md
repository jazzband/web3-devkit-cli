# RainbowKit integration

Generated by `web3 add rainbowkit`.

## Files

| Path | Purpose |
|------|---------|
| `lib/web3/chains.ts` | Supported EVM chains |
| `lib/web3/wagmi-config.ts` | RainbowKit + wagmi config |
| `components/web3/providers.tsx` | Wallet provider wrapper |
| `components/web3/connect-button.tsx` | RainbowKit connect UI |
| `lib/web3/transaction.ts` | Contract + native tx helpers |
| `hooks/use-contract-read.ts` | Read contract hook |
| `hooks/use-contract-write.ts` | Write contract hook |

## Setup

1. Install dependencies (CLI merges these into `package.json` when possible):

   ```bash
   npm install @rainbow-me/rainbowkit wagmi viem @tanstack/react-query
   ```

2. Add to `.env.local`:

   ```env
   NEXT_PUBLIC_WALLET_CONNECT_PROJECT_ID=your_walletconnect_cloud_id
   NEXT_PUBLIC_RPC_URL=https://...
   ```

3. Wrap your app layout:

   ```tsx
   import { Web3Providers } from "@/components/web3/providers";

   export default function RootLayout({ children }) {
     return (
       <html>
         <body>
           <Web3Providers>{children}</Web3Providers>
         </body>
       </html>
     );
   }
   ```

4. Use `<ConnectButton />` from `@/components/web3/connect-button`.
